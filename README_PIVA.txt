1. Coloque o seu arquivo CSV na pasta do projeto (ou use o caminho onde ele estiver).

2. Execute o comando abaixo no terminal para compilar e rodar a versão Multithread (substitua pelo caminho do seu CSV):

make run_mt DATASET=caminho/do/seu_arquivo.csv

Exemplo:
make run_mt DATASET=data/dataset_raw.csv

Os resultados do processamento e o tempo de execução de cada fase vão aparecer direto na tela!
